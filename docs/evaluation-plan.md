# 产品验收计划

供三人联调、组会和交付使用，描述要验证的产品行为，不记录 Agent 内部测试命令或历史批次。当前实现/缺口见[PRD](prd.md)，任务归属见[协作](collaboration.md)。

## 1. 证据分层

| 层次 | 能证明 | 不能据此宣称 |
| --- | --- | --- |
| 类型/schema/接口检查 | 契约可解析，静态约束一致 | 界面已接线、真实模型或数据库已部署 |
| 合成数据/注入HTTP/SDK离线测试 | 规则、流程、故障分支及本地提交 | 真实供应商可用、评分准确或真人效果 |
| 授权真实供应商调用 | 请求、返回、usage与对应技术链路 | 人工认可评分、硬件录音可用、教学改善 |
| Windows界面/设备/安装 | 在指定机器可安装操作、录音/播放与数据保留 | 任意环境或长期可靠性 |
| 独立人工参考与真实复测 | 指定样本上的质量/描述性变化 | 合成结果等于真人、分数上涨等于因果效果 |

没有执行的验收写“未验证”，失败保留；不靠改标签、删难例或更换分母制造通过。

## 2. 两端联调清单

| 场景 | 必须观察到的行为 | 主责 |
| --- | --- | --- |
| 双岗面试 | 创建→规划→答题→收尾→报告，Java/Web 场景和量规明显不同 | 三人 |
| 正常/澄清/弃评/零分 | 信息不足请求补充；明确不会可弃评；有效错误断言可零分；界面明确区分 | Agent＋前端 |
| 语音 | 麦克风→规范音频→ASR→确认→正式答题；TTS真实可播放；旧题/重复确认不能重复评分 | 前端＋Agent |
| 报告与面板 | 分数有来源/证据；文字无语音分；没有数据不填零；画像/成长注明岗位、版本和样本 | 三人 |
| 本机持久化 | 重启仍可查会话/记忆/任务，幂等重放不重复写，unknown 不自动重试收费 | 后端＋Agent |
| 提示与奖励 | 提示受控、记录辅助状态；失败/重复操作不重复扣奖，复测不叠加面试奖励 | 后端＋前端＋Agent |
| 学习复测 | 自报/核实分开，同技能不同题、未出题前隐藏题目；历史与新表现可关联 | 三人 |
| 账号隔离 | 换号不串 profile，过期令牌不能访问管理资源，学生不能调用admin API | 后端＋前端 |
| 内容审核/分发 | draft不可冒充正式，审核绑定版本/摘要；更新失败保留旧版，面试固定原版本 | 后端＋前端＋Agent |
| 管理三模块 | 监控只读、数据授权/分组可追溯、实验有预算/逐例结果；未发布不可展示启用成功 | 后端＋前端＋Agent |
| 安装与升级 | 非开发机Windows安装/启动/录音/退出，升级备份迁移，用户数据与资源分离 | 前端＋后端 |

## 3. 内容与评分质量

每岗目标60条人工核对回答（30开发/10验证/20最终），题库目标40题；这些是团队目标，未收集的不计完成。岗位人员独立盲审，保留rubric/题答版本、审核者与分歧；AI草案可供开发，但不作独立人工结论。

覆盖正常、缺证据/澄清、明确不会/弃评、有效错误断言/零分及验证目标题；核对各维度得分、原文引用是否支持结论、建议可执行性、承接是否准确或泄题。表达观察另做噪声、术语、短音频验证，ASR confidence不是学生自信，情感估计不是心理诊断。

指标记录分子分母、缺失/排除与版本：协议成功率、行为分支符合率、人工评分MAE/一致性、引用支持度、真实追问命中率。协议合法和引用位置正确都不能替代语义质量。

## 4. 双闭环与RSI

学生成长、系统评估校准与策略实验分别报告。学习后进步不能直接算原mastery的误差；预测需在看到复测题/答案前冻结，并满足岗位/技能/难度/量规、学习暴露和有效期规则后配对。

现有校准就绪至少8个合格配对、至少2名学生，并满足来源/独立参考等条件；不足返回未就绪与空指标，不伪造样本。该工程阈值不是统计充分性保证，也不等于所有策略实验都已达标。

策略候选仅改白名单参数，对固定且隔离的数据作基线/候选比较，核对命中、覆盖、评分不退化和成本。失败保留旧版并审计；合成改善、真人描述性结果与正式发布分开。评测达标不等于发布/客户端采用，发布链路未验收继续not_published。

## 5. 交付记录

每次组会记录本周新增、运行环境、版本/数据来源、真实/合成、实际通过/失败和未运行项；排期见[协作](collaboration.md)。最终交付Windows安装包、源码、两端说明、接口/数据契约与可复现证据。原型数字、历史CLI成功或本地构建不能代替双端验收。
