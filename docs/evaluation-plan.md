# 评测计划 v0.1

已实现[反思与合成策略评测](agent-reflection.md)：固定4例/3组工程场景演示基线2/4→候选4/4，分组及历史来源隔离，含零改善/退化拒绝。该工程小样例门槛不替代下文真实回答/合格复测配对门槛，不产生真人效果、评分校准或正式发布结论。

## 数据与指标

目标两岗各 60 条人工核对回答：30 开发、10 内部验证、20 最终验收。预标注分支场景单独维护，记录学生隐含技能、初始状态、候选问题/合法动作、后续回答、有效新增证据和时间约束。内部验证每版最多筛 3 个候选；最终集不用于自动门槛，不反复据其调参。

真人从 W3 招募，目标 8—12 人各至少两场，形成两岗合计 24 个有学习暴露记录的技能配对。这些是目标，当前为 0，不预设提升百分比。

### 预测与后续表现配对

工程实现现已见[学习与复测契约](learning-retest.md)：可运行事件/冻结预测/合格条件及分组MAE，但只验证合成fixture与元数据。真人合格配对仍为0。首版描述聚合另要求至少2学生，未改变正式统计充分性边界；不足返回null，不自动发布候选。

必须区分：同一回答的评分与人工参考之差、当前 mastery 与无学习暴露诊断题之差、学习后的真实成绩变化。第三种不能直接称作原 mastery 的校准误差。

推荐学习计划时，额外保存 PredictionSnapshot：predictedAt、targetSkill、expectedLearningExposure、validUntil、rubricVersion、predictedTargetScore、输入证据引用、预测器版本。初始预测期限为 7 天，预测值在看到复测题或答案前固定，与当前 mastery 独立命名。

复测的岗位、技能、难度、学习暴露、期限及 rubric 满足条件时，才能用 predictedTargetScore 与人工参考锚定分计算 MAE（同为 [0,1]）；不符合条件标 ineligible，仍可作描述性成长记录。学习完成的自报与可核实证据分开，点击不算完成。

初始自动候选门槛为同岗位至少 8 个合格配对，批次与岗位幂等；数据不足则跳过，不伪造样本。此阈值是可版本化的团队初值，不是统计充分性的保证。候选参数只能在预设白名单/范围/单次变化上限内调整，绑定 pairId、触发原因、前后值与预期指标；不能由模型修改门槛来确保自己通过。

主指标：真人追问命中率（独立盲审）；自动门槛代理：固定分支场景命中率。辅指标：人工参考评分 MAE、带条件/期限预测的复测 MAE、覆盖、无信息重复、资源完成率、失败率、延迟、用量。报告分子分母、缺失/排除样本与版本，真人/合成/回放分开。

自动启用：约束全过、场景命中率改善、覆盖与静态评分不退化、成本/调用预算合格，事务更新实验范围 champion；真实自由生成问题仍需独立审核。失败保留旧版，不能通过改门槛掩盖失败。预测快照在知道复测题/答案前固定；学习增益不等于原 mastery 错误。

## 关键反例

- 离线实验新操作须重新评测完整输入；调用方附passed摘要拒绝，合法失败保留active并追加审计。
- 回退后重放旧启用请求不应再次切换，旧pin也不得随active改变；同ID不同内容、新版本冲突和向后代“回退”拒绝。
- JSON恢复只核对审计结构/算术，不等于原验证集重跑或可信数据库恢复；正式CAS/认证/在途会话绑定另做验收。

- 历史恢复后仍是本场0轮/version0，不提前触发maxTurns；covered与当前会话覆盖不混淆。
- 原证据时间随7天半衰期衰减，不能因重新开场刷新；重做同题不增加独立证据或替换首次成绩。
- 跨学生/岗位或损坏记忆拒绝；完成会话A、B追加后重放A仍幂等，容量超限不静默丢历史。
- 历史离线来源/量规版本传递到报告，不因本场live声明掩盖合成证据；JSON往返不当成数据库重启恢复。

- 资源草案/失效/未核验/过期/未来核验时间均不进入默认推荐，等级不匹配不随意兜底。
- 工具参数混入URL/userId拒绝；畸形目录URL应返回契约错误而不是原始TypeError。
- 空查询消耗预算，查询跨期限或最后await期间取消不得返回增强报告；推荐状态保持not_started，不伪造完成与学习增益。

- 报告不得接受仅改normalizedScore的伪造结果，需用原量规和证据重算；错配answer/session/version或缺轮次拒绝。
- 未考察技能保持null，重复原题不提高独立覆盖；不同量规保留分维与版本，不生成不可比较的整场总分。
- 混合/离线来源显式展示，语音指标缺失；资源未接入时为空，不编造链接、学习完成或提升结论。

- Pi评估会话重复调用各自只有当前用户载荷，无工具声明/历史assistant；最终JSON合法但stopReason=length仍拒绝。
- 模型尝试工具调用、输出额外身份字段或代码块JSON均拒绝，不自动修复；provider错误与结构错误分开。
- 选题排除已发未答与历史已答，难度相同按ID稳定选择；缺当前技能题时返回缺口，不换到别岗或悄悄改变规划。
- reviewed可正常选，draft默认不选；行为题不强行套入当前technical-content量规。

- 最后一轮相同，历史证据/置信度不同，规划应合理变化；只按技能 ID 关键词选题不得通过。
- 背定义流畅但场景题失败；重复原题不能提升独立证据数。
- 模型传另一个 roleId/任意 URL/userId，执行器拒绝；取消或预算耗尽不能绕过。
- 噪声/短音频、ASR 修改文、口音、情感不确定时缺失值合理；ASR confidence 不代表自信度。
- 重复提交、取消/完成竞态、旧 attempt、断流重连与重启恢复需在正式业务迭代加入集成测试。
- 文本回答没有声学维度，不能填零拉低成绩或冒充已评估语音。

## 最终报告

当前新增的离线单轮测试只验证端口契约、证据出处、算术、状态更新与控制流，不计入模型准确率。真实模型后续按两岗独立人工参考集测试维度成绩/反馈证据支持；没有描述锚点和审核的 draft rubric 不作为正式校准标准。fixture 手工给分必须标为合成，不能产生“系统评分改善”的真实结果。超时/取消测试含忽略信号的挂起端口，证明宿主停止等待，不证明远端计算已停止。

包括测试环境、命令、样本/数据版本、成功与失败、成本及证据路径。只有实际执行的检查写通过；没有运行的 GUI、数据库、真实模型、供应商取消和安装包单列。每周按六个评分维度更新证据，功能冻结为 12/6，12/7—18 回归与交付；周次与负责人见[协作说明](collaboration.md)。
## 固定离线验收入口

`bun run agent:acceptance` 执行双岗十二个固定成功/拒绝场景，导出 JSON/Markdown。默认八例走真实本机 TCP，四例为明确宿主调用；不替代本文件规定的人工参考集和真实效果评测。报告摘要、源码匹配与校验/重跑区别见 [离线验收说明](agent-acceptance.md)。

## 回答草案参考与误差分析

`bun run agent:answers:eval`接真实Pi SDK的本地固定半分provider，按岗位输出草案参考MAE、偏差、缺分分歧与失败计数。18条合成回答/参考全部未审核，开发/验证/预留最终各6例；预留最终不可执行，人工参考数仍0，不改变上文目标或manifest真人计数。标签不进入推理请求，来源/量规/回答绑定和分组隔离有效；细节见[回答基准](answer-benchmark.md)。
