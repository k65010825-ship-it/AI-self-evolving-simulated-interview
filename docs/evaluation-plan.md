# 评测计划 v0.1

范围：完整产品验收与开发回归。当前尚无真实模型、ASR、真人复测或 RSI 改进数据；实现状态见 [PRD](prd.md)。

## 分层验证

| 层 | 输入与检查 | 能证明/不能证明 |
| --- | --- | --- |
| 静态 | 严格类型、公开 SDK 导出、Zod/JSON schema、OpenAPI | 契约可编译/可解析；不证明在线质量 |
| 单元 | 实际种子查询、岗位隔离、预算、取消、空结果、纯规划优先级 | 本地规则行为；不证明数据库/供应商 |
| SDK 离线 | 真实 Pi＋确定性本地 provider | 工具循环、事件、历史恢复和取消；不证明 LLM 自主决策 |
| 服务骨架 | Hono app.request 健康/未实现错误 | 路由行为；不证明登录/面试已交付 |
| 真实模型 | 授权供应商、固定模型与预算、两岗样例 | 工具选择/内容/schema/时延成本，必须另行执行 |
| 桌面/安装 | 非开发机 GUI、麦克风、重连、安装与升级提示 | 用户可用性；单纯打包/构建不能替代 |
| 双闭环 | 实际学习/复测配对、自动候选与实验 | 系统改进与学生成长分开，不从分数上涨推因果 |

## 数据与指标

目标两岗各 60 条人工核对回答：30 开发、10 内部验证、20 最终验收。预标注分支场景单独维护，记录学生隐含技能、初始状态、候选问题/合法动作、后续回答、有效新增证据和时间约束。内部验证每版最多筛 3 个候选；最终集不用于自动门槛，不反复据其调参。

真人从 W3 招募，目标 8—12 人各至少两场，形成两岗合计 24 个有学习暴露记录的技能配对。这些是目标，当前为 0，不预设提升百分比。

### 预测与后续表现配对

必须区分：同一回答的评分与人工参考之差、当前 mastery 与无学习暴露诊断题之差、学习后的真实成绩变化。第三种不能直接称作原 mastery 的校准误差。

推荐学习计划时，额外保存 PredictionSnapshot：predictedAt、targetSkill、expectedLearningExposure、validUntil、rubricVersion、predictedTargetScore、输入证据引用、预测器版本。初始预测期限为 7 天，预测值在看到复测题或答案前固定，与当前 mastery 独立命名。

复测的岗位、技能、难度、学习暴露、期限及 rubric 满足条件时，才能用 predictedTargetScore 与人工参考锚定分计算 MAE（同为 [0,1]）；不符合条件标 ineligible，仍可作描述性成长记录。学习完成的自报与可核实证据分开，点击不算完成。

初始自动候选门槛为同岗位至少 8 个合格配对，批次与岗位幂等；数据不足则跳过，不伪造样本。此阈值是可版本化的团队初值，不是统计充分性的保证。候选参数只能在预设白名单/范围/单次变化上限内调整，绑定 pairId、触发原因、前后值与预期指标；不能由模型修改门槛来确保自己通过。

主指标：真人追问命中率（独立盲审）；自动门槛代理：固定分支场景命中率。辅指标：人工参考评分 MAE、带条件/期限预测的复测 MAE、覆盖、无信息重复、资源完成率、失败率、延迟、用量。报告分子分母、缺失/排除样本与版本，真人/合成/回放分开。

自动启用：约束全过、场景命中率改善、覆盖与静态评分不退化、成本/调用预算合格，事务更新实验范围 champion；真实自由生成问题仍需独立审核。失败保留旧版，不能通过改门槛掩盖失败。预测快照在知道复测题/答案前固定；学习增益不等于原 mastery 错误。

## 关键反例

- 最后一轮相同，历史证据/置信度不同，规划应合理变化；只按技能 ID 关键词选题不得通过。
- 背定义流畅但场景题失败；重复原题不能提升独立证据数。
- 模型传另一个 roleId/任意 URL/userId，执行器拒绝；取消或预算耗尽不能绕过。
- 噪声/短音频、ASR 修改文、口音、情感不确定时缺失值合理；ASR confidence 不代表自信度。
- 重复提交、取消/完成竞态、旧 attempt、断流重连与重启恢复需在正式业务迭代加入集成测试。
- 文本回答没有声学维度，不能填零拉低成绩或冒充已评估语音。
