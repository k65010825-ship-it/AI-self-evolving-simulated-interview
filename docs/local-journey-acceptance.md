# 双岗完整会话与异常恢复验收

执行 `bun --no-env-file run agent:local:journey`。仅离线合成数据，不读取真实凭证，不发供应商请求。产物在 `.cache/journey-acceptance/run-*/report.json`、`review.md`、`recovery.log`，绑定源码清单/摘要并保留子验收产物路径。

## 证据通道

1. 直接宿主混合会话，每岗独立临时profile：正常作答→新题→提示1→澄清→重启→提示2及第三次拒绝→合成音频分块上传/确认→辅助作答评分→实际发出第三道未见题→继续至新策略八轮上限→报告/记忆→重启回执/事件重放→下一场记忆召回。hint repository为SQLite测试fixture，非正式实现。
2. 独立新profile辅助弃评，每岗一例：提示→缺证据澄清→再次不确定→弃评→报告null、记忆不新增。它是单独的评分行为分支，不拼作混合会话中的真实作答。
3. 实际生产文字sidecar构建/stdio验收：现有accept-local-agent；从独立cwd启动、两岗会话/正式回执、重启/下一场记忆，默认确定性provider。
4. 单独构建注入式语音测试sidecar：实际Pi、私有凭证帧及stdio，供应商HTTP/凭证/音频全部合成；验证ASR/TTS/确认/账本。不是生产安装包或真实硬件。
5. 恢复专项：既有租约/候选过期、原子对账/回执、live任务恢复、进程生命周期、启动诊断、双岗澄清连续性测试。退出码、测试计数和日志摘要一并保存，失败不自动重跑。

## 结论与未通过项

`mechanismStatus`表示这些离线动作/断言是否通过；两岗连续合成体验检查均执行通过且无发现时experienceStatus=passed。CLI仅在两者均passed时退出0，机制失败为1，体验有发现或未完整执行为2。合成体验通过不代表真人评分质量、15—25分钟真实节奏或生产提示存储已验收。

新会话固定draft-preview目录及精确历史兼容清单，显式启用有界换技能回退。种子耗尽回退、Top-K遮蔽、全目录耗尽零模型调用、有效计划/反思绑定及旧语义另由tests/question-fallback.test.ts验证。旧run-*报告保留原发现，不改写为通过；新报告只描述本次实际执行。当前已接入双岗六主技能草案与跨技能有界回退（local-v4）；人工独立审核、正式持久化 repository、桌面与安装仍不在本次通过或交付范围。

本次连续场景同时核验辅助来源在正式报告、记忆和候选提交门控保持一致，删除报告辅助标记须拒绝。正式提示repository、真人答案、独立审核、真实语音/设备、桌面与安装均不在“通过”范围。
